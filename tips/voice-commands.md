# Voice Commands Reference

Quick reference for useful Tesla voice commands. Not a checklist — no phase,
no order. Use it as a lookup when you forget a command exists.

## Activating voice

- **Model 3 / Model Y**: press the right scroll wheel, wait for the beep,
  speak naturally.
- **Model S / Model X**: press the microphone button on the steering wheel.

You don't need to memorize exact phrasing. Tesla matches intent, not keywords.

## Before relying on dashcam or Sentry

The USB drive in the glovebox must be correctly formatted or neither feature
records anything. Format: **exFAT** on current software (FAT32 on older
versions). If you've never verified this, plug the drive into a laptop and
check before you count on having footage.

## Climate & Comfort

| Say this | What it does |
|----------|--------------|
| `Keep climate on` | Maintains cabin temp after you exit — no screen message, just keeps the system running. Good for short stops. |
| `My butt is cold` / `My butt is hot` | Driver seat heater on / off. |
| `My hands are cold` | Heated steering wheel on (Model S, Model X, 2021+ Model 3/Y). |
| `My feet are hot` | Redirects airflow to foot vents. |
| `Turn on recirculate` | Closes fresh-air intake; recirculates cabin air. Useful behind a diesel truck, in construction dust, or poor air quality. |
| `Activate pet mode` | Keeps cabin temp + displays "owner will be back" message on screen. |
| `Turn on camp mode` | Keeps climate, lights, and USB power running overnight without the car sleeping or the alarm triggering. |

## Dashcam & Security

| Say this | What it does |
|----------|--------------|
| `Save` | Locks the last 10 minutes of dashcam footage immediately. No screen tap, no hands off the wheel. Use when you witness something on the road. |
| `Enable Sentry Mode` | Activates Sentry. Also works: `Keep summer safe`, `Keep my car safe`, `Keep Tesla safe`. |

## Navigation

| Say this | What it does |
|----------|--------------|
| `Navigate home` / `Take me to work` | Routes to your saved home or work address. |
| `Navigate to [nickname]` | Routes to any saved location by name — "navigate to dad's house," "take me to the gym." |
| `Show nearby Superchargers` | Populates the map with charging options around your current location. |
| `Find coffee` / `Find burgers` / `Find sushi` | Returns nearby results filtered by type. More specific than "I'm feeling hungry." |
| `Use HOV lanes` / `Don't use HOV lanes` | Controls carpool lane routing on the fly. |
| `I'm feeling hungry` | Pulls up a ranked list of nearby restaurants. |

## Vehicle Controls

| Say this | What it does |
|----------|--------------|
| `Fold mirrors` / `Unfold mirrors` | Folds or opens side mirrors instantly — faster than the menu when pulling into a tight space. |
| `Open glove box` | Opens the glovebox. Routes to the PIN prompt if PIN-protected. |
| `Open charge port` / `Close charge port` | Opens or closes the charge port door. |
| `Set acceleration to chill` / `Set acceleration to standard` | Changes power delivery mode on the fly — useful handing the car to someone unfamiliar, or pulling out onto wet roads. |
| `Set steering weight to light` / `standard` / `heavy` | Adjusts steering feel in real time. |
| `Speed up the wipers` / `Slow down the wipers` | Adjusts wiper rate without touching the screen. |
| `Turn on the rear defroster` | Activates rear window defroster by voice. |
| `Turn on dark mode` | Switches the interface to dark mode immediately. |
| `Increase screen brightness` / `Decrease screen brightness` | Adjusts display brightness without going into settings. |
